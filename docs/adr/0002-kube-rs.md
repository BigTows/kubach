# 0002 — kube-rs для ядра

Статус: принято

## Контекст
Ядру нужен клиент Kubernetes API с поддержкой kubeconfig, watch и динамических ресурсов (CRD).

## Решение
Строить `kubach-core` на [`kube-rs`](https://kube.rs). Крейт не имеет UI-зависимостей.

## Последствия
- Готовые list/watch, reflector и динамические API.
- Ядро тестируется и переиспользуется (в том числе MCP) без UI.
- Привязка к async-рантайму (tokio): на границе с GPUI её нужно оформить аккуратно.
  Вопрос решён в [ADR 0011](0011-async-runtime.md): общий рантайм, задачи с владельцем и отменой.
