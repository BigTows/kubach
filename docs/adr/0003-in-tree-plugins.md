# 0003 — Только встроенные плагины

Статус: принято (контракт действий уточнён в #207)

## Контекст
Поддержка разных типов ресурсов (Pods, Deployments, CRD…) должна быть расширяемой.

## Решение
Плагины — только встроенные (in-tree), реализуют трейт `ResourcePlugin` и компилируются
вместе с приложением. Динамическая загрузка сторонних плагинов не поддерживается.

### Контракт действий (#207)
- Действие — `Action { id: ActionId, title, dangerous, kind: ActionKind }`. Общие id —
  константы `plugin::builtin::action` (`DELETE`, `SCALE`, `LOGS`…), id типизирован
  (`ActionId`), строки в UI и MCP не сравниваются.
- `ActionKind::Api` — запросы к API-серверу. Их исполняет **один** метод
  `run_action(client, obj, &ActionId, &ActionParams)`; параметры (`replicas` для scale)
  передаются в `ActionParams`, которые описывает `action_params`. Детали, массовые
  действия (`plugin::bulk`) и MCP вызывают один и тот же метод; bulk передаёт пустые
  параметры и не предлагает действия, у которых они есть.
- `ActionKind::Stream(StreamKind)` — `Logs`, `Exec`, `PortForward`, `Debug`. Плагин их
  только объявляет; открывает поток вызывающий: dock (`dock::target`) выбирает вид
  потока по `StreamKind`, MCP — отдельными инструментами (`get_logs`, `exec`).
  `run_action` такие действия не исполняет (`PluginError::Stream`) и ничего не отправляет.
- Delete есть у любого вида: `GenericPlugin` (CRD и встроенные виды без своего плагина)
  удаляет через discovery группы-версии (плюрал и scope не угадываются по kind), GitOps-
  плагины — по известному плюралу. Везде `DeleteParams` из `delete_params()`
  (Background propagation, как `kubectl delete`). Обходного пути удаления в MCP нет;
  проверки политики MCP для delete прежние.
- Плагин не объявляет действие, которое не умеет выполнять (Drain у Node скрыт до
  реализации): объявленное действие всегда исполнимо или является потоком.

## Последствия
- Нет ABI-проблем и вопросов безопасности недоверенного кода.
- Единый стиль и тестирование, проще релизы.
- Запросы действий проверяются fake-API тестами (`plugin/builtin/action_tests.rs`), один
  путь для UI, bulk и MCP.
- Удаление CRD стоит лишнего discovery-запроса к группе-версии.
- Сторонние расширения возможны только через PR в репозиторий; решение можно пересмотреть новым ADR.
