# 0001 — GPUI для десктопного UI

Статус: принято

## Контекст
Нужен кроссплатформенный (macOS, Windows, Linux) быстрый десктопный UI на Rust, способный
плавно показывать большие списки ресурсов.

## Решение
Использовать [GPUI](https://gpui.rs) с компонентами [GPUI Kit](https://gpui-kit.com) (`gpui-kit 0.8`).
Собственная дизайн-система живёт в `kubach-ui`.

## Последствия
- Нативная производительность, единый язык с ядром.
- GPUI молодой, API нестабилен; версии фиксируем в workspace.
- В dev-профиле зависимости собираются с `opt-level = 3`, иначе прокрутка тормозит.
